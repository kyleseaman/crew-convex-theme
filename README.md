# Convex theme for Kiro Crew

A Kiro Crew theme pack inspired by [convex.dev](https://convex.dev).

- **Dark:** warm espresso-brown surfaces, off-white text, Convex yellow (`#f3b01c`) accent.
- **Light:** cream surfaces, dark brown text, Convex purple (`#8d2676`) accent.
- The yellow / red / purple Convex stripe under the top bar.
- Pill-shaped primary buttons and softer code-block corners.
- Uses Kiro Crew's own fonts.

## Install

In Kiro Crew, open **Settings → Display → Install theme** and paste:

```
https://github.com/kyleseaman/crew-convex-theme
```

Re-installing from the same URL updates the theme.

## Contents

| File | Purpose |
|---|---|
| `theme.json` | Manifest (level 1: colours + overrides) |
| `variables.json` | Dark and light palettes |
| `styles/overrides.css` | Top-bar stripe, pill buttons, code-block radius |
